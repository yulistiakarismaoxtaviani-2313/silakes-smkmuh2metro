# Sistem Informasi Layanan Kesiswaan Berbasis Website

Repository ini berisi kode sumber skripsi dengan judul:

**Perancangan dan Implementasi Sistem Informasi Layanan Kesiswaan Berbasis Website pada SMK Muhammadiyah 2 Metro**

## Deskripsi

Sistem ini dikembangkan untuk membantu pengelolaan layanan kesiswaan di SMK Muhammadiyah 2 Metro. Sistem menyediakan fitur pengelolaan data siswa, presensi, prestasi, pengumuman, jadwal pelajaran, dan jadwal ujian.

## Teknologi yang Digunakan

- Laravel 12
- PHP 8.2
- MariaDB
- Tailwind CSS
- Vite

## Fitur

- Login Multiuser
- Manajemen Data Siswa
- Presensi Siswa
- Prestasi Siswa
- Pengumuman
- Jadwal Pelajaran
- Jadwal Ujian
